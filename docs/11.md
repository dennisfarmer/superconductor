# 11.md: ElevenLabs ideas for SuperConductor Atlas (pinned)

We have the ElevenLabs **Creator** plan (`ELEVENLABS_API_KEY` in `.env`; the `elevenlabs` SDK is
already in the conda env). Nothing below is built yet. The prototype first had to prove that the
graph search and the Magenta stream work. Check each feature's availability and quota on the
Creator plan before building on it.

## ★ 1. The Narrator (the pinned idea, and the thread that ties the demo together)

A voice that explains the harmony *as you move through it*, using facts the Jac walker already
computed.

- **Where the words come from:** the `describe` endpoint in `services/atlas.jac` (byllm →
  `PathStory {title, mood, explanation}`) already writes a grounded script. It only ever sees the
  walker's own data: the syntax rule for each move, voice-leading marks, and the cadence type.
- **Voice:** use **Voice Design** to create one narrator character (e.g. "a warm, unhurried
  composition teacher, late 50s, faint smile in the voice"), then **TTS** (Flash/Turbo models for
  low latency) to speak the text.
- **When it speaks:** on *commit* ("vi, a tonic extension; you're leaving home without really
  leaving"), on reaching a **cadence** ("that's a deceptive cadence, which is why it feels like a
  door opening onto the wrong room"), and on demand for a pinned path.
- **Mixing with Magenta:** play the voice in the browser. The Magenta stream keeps going
  underneath, and the engine's `gain` setting can duck it while the narrator talks.
- **Why it matters for the pitch:** it turns "a graph search happened" into something the audience
  *hears* explained. Jac's walker finds it, byllm phrases it, ElevenLabs says it.

## 2. A voice per harmonic function

Give each function its own designed voice, and have a chord "speak" its pull when you hover it:
- **Tonic:** calm and settled.
- **Pre-dominant:** curious, leaning forward.
- **Dominant:** urgent, a little breathless.
- **Applied chords:** conspiratorial ("I'm only here to get you to ii").

It's playful and it genuinely teaches function. The text is generated from the chord's `func` and
its tendency tones.

## 3. Speech-to-text commands (Scribe STT)

"Take me somewhere darker and land on the relative minor."
- STT → byllm `parse_intent()` → a typed object `{target_cid, mood_weights, max_depth}`.
- The walker re-plans with those weights. The rule engine stays in charge; the LLM only sets goals.
- Hands-free for composers who are sitting at an instrument.

## 4. Cadence stingers (Sound Effects)

Short generated sound effects for UI moments that stay out of Magenta's way:
- a soft chime when a walker finds a PAC,
- a "page turn" when a path is committed,
- a low swell while walkers are out.

Generate them once and cache them as files. No per-event API calls.

## 5. "Hear it realised" (music generation, if the plan allows it)

Send the committed progression, with Roman numerals, tempo and a style prompt, to ElevenLabs
music generation. You get a finished, produced reference track to compare with Magenta's live
sketch. It's good for an end-of-demo payoff: *the sketch you explored → the song it could become*.

## 6. Dialogue mode: two theorists argue

Use a two-voice dialogue (a v3 dialogue / multi-speaker TTS) where a "Classicist" and a "Pop
producer" each argue for a different branch of the beam. For example, the classicist wants the
cadential ⁶₄ and the producer wants ♭VII → I. The walker supplies both paths and their scores.
It's great stage theatre for the final presentation.

## 7. Conversational agent (stretch goal)

An ElevenLabs Agent with the Jac endpoints as tools (`explore`, `audition`, `commit`), so you can
talk to the atlas: "play me the three most surprising ways out of here." That's a big lift, so
only attempt it if 1–3 are done.

---

**Suggested order:** 1 (narrator) → 4 (stingers, cheap) → 3 (voice commands) → 6 (dialogue, for
the demo) → 5 (plan permitting).
